# Faiz Fawad — Resume Website

## Files
- `index.html` — complete responsive portfolio website (HTML, CSS, JavaScript).

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a new public GitHub repository (for example: `faiz-fawad-portfolio`).
2. Upload `index.html` to the repository root and commit the change.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish. The URL will usually be:
   `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`
7. Open the URL in a private/incognito browser window to verify it is public.
8. Paste both the repository URL and live website URL into the Word assignment.
